  FIX AUTO MODE - Use PuTTY Database Command
═══════════════════════════════════════════════════════════

QUICKEST FIX: Run this ONE command in PuTTY:

cd /home/pi/RDWC-v4 && sqlite3 data/rdwc.db "UPDATE settings SET value='auto' WHERE key='unified_mode'; SELECT key, value FROM settings WHERE key='unified_mode';"

You should see:
unified_mode|auto

Then refresh your browser with Ctrl+Shift+F5

═══════════════════════════════════════════════════════════
WHY THE API HANGS:
═══════════════════════════════════════════════════════════

Database lock or timeout (10 second timeout × 3 retries = 30s hang)
The sensor poller might be holding a lock on the database.

═══════════════════════════════════════════════════════════
IF PUMPS STILL DON'T START AFTER AUTO MODE:
═══════════════════════════════════════════════════════════

Main pump needs a schedule or explicit circulation control.

To manually turn on main pump:

curl -X POST http://localhost:8080/api/relays/main_pump \
  -H "Content-Type: application/json" \
  -d '{"state":true,"reason":"manual_start"}'

Or from Windows:
Invoke-RestMethod -Uri "http://192.168.88.49:8080/api/relays/main_pump" -Method POST -Headers @{"Content-Type"="application/json"} -Body '{"state":true,"reason":"manual_start"}'
